# Neurolink Blog

To add new blog posts to blog.neurolink.ink:

Create a new file in _posts/ with format: YYYY-MM-DD-title.md
Add front matter:

markdown---
layout: post
title: "Your Post Title"
date: 2025-01-10
categories: category-name
---

Your content here...

Commit and push:

bashgit add _posts/2025-01-10-your-post.md
git commit -m "Add new blog post"
git push origin main
