# About NeuroLink Blog

This blog provides tutorials, guides, and updates for [NeuroLink](https://github.com/juspay/neurolink) - the unified AI SDK that simplifies integration with multiple AI providers.

## What is NeuroLink?

NeuroLink is an open-source TypeScript/JavaScript SDK that provides:

- **13 Native Providers**: OpenAI, Anthropic, Google, Azure, AWS Bedrock, Mistral, and more
- **Unified API**: One interface for all providers
- **Multimodal Support**: PDFs, CSVs, images, audio, video
- **Enterprise Features**: HITL, Guardrails, Memory, MCP Tools
